# Benchmark — 盲测对比实验

本目录收录 Survey Machine 与主流 AI 系统（ChatGPT 5.4 Plus）的综述生成盲测对比结果。

---

## 测试方法

1. 选取相同的研究主题
2. 使用相同的 Prompt（见各子目录 `prompt.txt`）
3. 分别交由 ChatGPT 5.4 Plus 和 Survey Machine 生成综述
4. 由独立评委（不知晓来源）按 8 维度质量体系评分

---

## 测试案例

### 1. 强化学习飞行控制综述

| 维度 | Survey Machine | ChatGPT 5.4 Plus |
|------|:--------------:|:-----------------:|
| 结构完整性 | 满分 | 截断 |
| 内容深度 | 35页，80+引用 | 明显不足 |
| 图表质量 | 8张专业框图 | 无图表 |
| 引用规范 | 标准 thebibliography | 含 ?? |
| **综合得分** | **A+（90+）** | **未达标** |

**优势幅度：Survey Machine 得分比 ChatGPT 高 50%+**

### 2. LLM Agent 规划与执行综述

- 主题：大语言模型作为自主智能体的规划与执行引擎
- Survey Machine 输出：完整 LaTeX + PDF，含文献引用
- ChatGPT 输出：结构化但不完整

### 3. 人工智能与全球战略稳定性综述

- 主题：自主武器、军备竞赛与威慑模型的重构
- Survey Machine 独立生成，质量 A+（90+）
