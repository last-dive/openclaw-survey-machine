## 详细迭代记录

### Round 1: 文档截断问题

**现象**: 生成的PDF只有5页，内容明显不完整

**诊断**:
```bash
# 检查文档结构
grep -n "end{document}" survey.tex
# 输出:
# 151:\end{document}
# 1094:\end{document}
```

**根因**: 第151行有错误的`\end{document}`，导致文档在第1章后截断

**修复**:
```python
# 删除第151行的\end{document}
content = content.replace('\n\\end{document}\n', '', 1)
```

**结果**: 文档恢复到34页

---

### Round 2: 引用失败问题

**现象**: 正文中出现`[??]`，引用未定义

**诊断**:
```bash
grep -o "\[\?\?\]" survey.tex | wc -l
# 输出: 15
```

**根因**: 文献编号在正文中手动编写，未使用`\cite{}`命令

**修复**:
```latex
% 错误
Smith预估器[1]是经典方法。

% 正确
Smith预估器~\cite{smith1957}是经典方法。
```

**结果**: 消除所有`[??]`

---

### Round 3: 格式问题

**现象**: 
1. 孤立列举 `(1)(2)(3)(4)`
2. 单行itemize
3. 交叉引用换行

**示例**:
```latex
% 问题：孤立列举
(1) 影响飞行稳定性
(2) 降低控制精度
(3) 增加能量消耗
(4) 限制通信距离

% 修复：改为表格
\begin{table}
\begin{tabular}{@{}ll@{}}
\toprule
影响方面 & 具体表现 \\
\midrule
飞行稳定性 & ... \\
控制精度 & ... \\
... & ... \\
\bottomrule
\end{tabular}
\end{table}
```

**修复策略**:
1. 列举→表格 (三线表)
2. itemize→连续叙述
3. `\ref{}`→`~\ref{}`

---

### Round 4: 引用系统错误

**现象**: 使用`enumerate`环境做参考文献

**错误代码**:
```latex
\begin{enumerate}
\item Smith, O. J. (1957). ...
\item Krstic, M. (2009). ...
\end{enumerate}
```

**正确代码**:
```latex
\begin{thebibliography}{99}
\bibitem{smith1957} Smith, O. J. (1957). ...
\bibitem{krstic2009} Krstic, M. (2009). ...
\end{thebibliography}
```

**关键区别**:
- `enumerate`: 手动编号，无法使用`\cite{}`
- `thebibliography`: 标准引用系统，支持`\cite{}`交叉引用
