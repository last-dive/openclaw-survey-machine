## 工作流程

### Phase 0: 可视化规划（新增，10min）

**目标**: 在撰写前规划所有插图

**步骤**:
1. 分析主题，确定需要哪些框图解释核心概念
2. 撰写生图提示词，调用seedream/TikZ工具
3. 生成并保存所有框图到`figures/`目录
4. 在框架中标注插图插入位置

**必含图表清单**:
- [ ] 方法分类框架图（树状结构）
- [ ] 三种平台/方法对比图
- [ ] 关键技术流程图
- [ ] Sim-to-Real技术路线图
- [ ] 算法对比表格
- [ ] 性能对比表格

**输出**: `figures/`目录（5+张图）

### Phase 1: 文献调研与阅读 (60min) [主代理亲自完成]

**目标**: 建立100+篇文献库，**主代理亲自阅读并理解**30篇关键文献

**核心原则**: 子agent可辅助检索，但**阅读和理解必须由主代理亲自完成**

**步骤**:
1. 全网检索 (arXiv, IEEE, ACM, 知网) —— 可委托子agent初步检索
2. 按主题聚类
3. 质量筛选 (顶会顶刊优先)
4. **关键步骤（主代理亲自）**: 逐篇阅读摘要，提取核心观点
5. **关键步骤（主代理亲自）**: 整理文献核心观点到`literature_notes.md`
6. **关键步骤（主代理亲自）**: 用自己的话复述每篇文献的贡献

**输出**:
- `literature_pool.json`（文献元数据）
- `literature_notes.md`（文献内容笔记，**主代理亲自撰写**）

**质量检查**:
- [ ] 主代理能否用自己的话复述每篇文献的核心贡献？
- [ ] 主代理能否比较不同文献的方法差异？
- [ ] 主代理能否指出各方法的局限性？
- [ ] 是否亲自阅读而非仅收集标题？

### Phase 2: 框架构建 (20min)

**目标**: 构建7章标准综述结构

**标准结构**:
```
第1章 引言
  1.1 研究背景与意义
  1.2 问题定义与挑战
  1.3 研究现状概述
  1.4 本文组织结构

第2章 基础理论
  2.1 核心概念定义
  2.2 数学建模
  2.3 经典方法回顾

第3章 方法A
  3.1 子类A1
  3.2 子类A2
  3.3 方法对比与局限性

第4章 方法B
  (同第3章结构)

第5章 方法C
  (同第3章结构)

第6章 实验与应用
  6.1 数据集与评测指标
  6.2 性能对比
  6.3 应用案例分析

第7章 未来方向
  7.1 技术挑战
  7.2 研究趋势
  7.3 展望
```

**输出**: `framework.yaml`

### Phase 3: 内容撰写 (4-5h) [主代理亲自完成，基于文献]

**目标**: 生成30+页深度综述，**主代理亲自基于真实文献内容撰写**

**核心原则**（必须遵守）:
1. **主代理亲自撰写**: 绝不委托子agent，确保内容深度和逻辑连贯
2. **基于文献笔记撰写**: 每个观点必须能在`literature_notes.md`中找到支撑
3. **禁止编造**: 不编造任何文献、数据、方法细节
4. **充实内容**: 每个小标题下至少3-5段深入阐述
5. **批判分析**: 每类方法必须有局限性分析（基于文献）
6. **追求标杆质量**: 以LLM_Survey_v3_2025.pdf为榜样，详细、完整、深入

**策略**:
- 每章按"原理→方法→局限→对比"展开
- 每类方法必须包含局限性分析
- 使用表格替代孤立列举
- 数学公式使用标准LaTeX
- **引用文献**: 每个关键观点后标注`~\cite{标签}`
- **深度优先**: 宁可减少章节数量，也要保证每章内容充实

**输出**: `survey_draft.tex`（主代理亲自撰写）

**质量检查**:
- [ ] 是否主代理亲自撰写而非子agent生成？
- [ ] 是否所有引用都能在`literature_pool.json`中找到？
- [ ] 是否存在空虚标题（只有一句话）？
- [ ] 是否每段都有实质性内容（3-5句）？
- [ ] 是否达到LLM_Survey_v3_2025.pdf的质量标准？

### Phase 4: 可视化 (30min)

**目标**: 生成5+张专业图表

**必含图表**:
1. 系统架构图 (TikZ)
2. 方法分类框架图 (TikZ)
3. 关键技术框图 (TikZ)
4. 方法对比表 (三线表)
5. 性能对比表 (三线表)

**TikZ最佳实践**:
- 使用绝对坐标 `at (x,y)`
- 统一间距 (水平3.5cm, 垂直2.5cm)
- 避免matrix布局
- 节点周围预留边距

**输出**: `figures/`目录

### Phase 5: 引用系统 (20min) [严格真实]

**目标**: 建立标准参考文献系统，**只包含真实文献**

**核心原则**:
1. **只引用调研到的文献**: 每条`\bibitem`必须对应`literature_pool.json`中的真实文献
2. **禁止凑数**: 绝不编造文献以达到数量要求
3. **数量诚实**: 如实反映调研到的文献数量（30篇就是30篇，不编造到100篇）

**必须使用**:
```latex
\begin{thebibliography}{99}
\bibitem{label1} 作者. 标题. 期刊, 年份.
\bibitem{label2} ...
\end{thebibliography}
```

**正文引用**:
```latex
Smith预估器~\cite{smith1957} 是经典方法。
```

**禁止**: 使用`enumerate`环境做参考文献

**质量检查**:
- [ ] 每条文献都能在原始数据库中找到？
- [ ] 文献信息（作者、标题、期刊、年份）准确无误？
- [ ] 是否存在编造文献？

### Phase 6: 质量检查与反思 (30min) [主代理亲自完成]

**核心原则**: 主代理亲自检查质量，亲自反思改进，绝不委托子agent

**6维度检查**:

| 维度 | 检查项 | 标准 |
|------|--------|------|
| 结构 | 章节完整性 | 7章完整，无截断 |
| 引用 | 引用系统 | 无`??`，标准thebibliography |
| 排版 | 格式规范 | 无孤立列举，交叉引用正确 |
| 可视化 | 图表质量 | 5+张，清晰无重叠 |
| 内容 | 学术深度 | 批判性分析>10处 |
| 规范 | 编译检查 | 无错误，无警告 |
| **诚信** | **文献真实性** | **100%真实，0编造** |
| **亲自** | **主代理完成度** | **核心工作亲自完成** |

**反思问题（主代理亲自回答）**:
1. 我是否亲自阅读了所有关键文献？
2. 我是否亲自撰写了每个段落？
3. 是否存在编造文献的情况？
4. 内容深度是否达到LLM_Survey_v3_2025.pdf的标准？
5. 如果博士评审，会指出哪些问题？

**输出**: `quality_report.md`（主代理亲自撰写）

## 失败案例规避

### ❌ 案例1: 文档截断

**现象**: 只有5页，内容被截断

**根因**: 第151行有错误的`\end{document}`

**规避**: 
- 生成后检查文档结构
- 搜索`\end{document}`确认唯一性
- 检查章节计数

### ❌ 案例2: 引用失败

**现象**: 正文中出现`[??]`

**根因**: 使用`enumerate`环境而非`thebibliography`

**规避**:
- 强制使用`\thebibliography`环境
- 每条文献必须有`\bibitem{标签}`
- 正文使用`\cite{标签}`引用

### ❌ 案例3: 孤立列举

**现象**: 文档中大量`(1)(2)(3)(4)`或单行itemize

**根因**: 生成时逐句处理，未合并

**规避**:
- 后处理合并为连续叙述
- 或改为三线表
- 检查单句成段现象

### ❌ 案例4: 框图重叠

**现象**: TikZ框图节点重叠、连接线错位

**根因**: 使用matrix布局，节点数量不一致

**规避**:
- 使用绝对坐标`at (x,y)`
- 统一间距参数
- 避免matrix of nodes

### ❌ 案例5: 学术诚信问题（致命）

**现象**: 编造虚假参考文献以凑页数

**根因**: 
- 调研的文献未真正阅读，仅收集标题
- 无话可写时用训练数据生成内容
- 面对页数不达标时编造文献

**后果**:
- 内行一眼识破，学术信誉受损
- 综述失去参考价值
- 严重违背学术伦理

**规避**（必须遵守）:
1. **文献必须真实**: 只引用实际检索到的文献，绝不编造
2. **基于文献撰写**: 必须阅读/理解文献内容后撰写，而非用训练数据生成
3. **充实而非编造**: 页数不够时，基于已有文献深入分析，而非创造新文献
4. **摘要即宝藏**: 100篇文献的摘要加起来远超50页，充分利用这些素材
5. **诚实标注**: 如某部分确实缺乏文献支撑，明确说明而非编造

### ❌ 案例6: 缺少框图

**现象**: 50+页综述没有一个框图

**根因**:
- 未在撰写前规划插图位置
- 未调用生图工具准备可视化
- 对调研结果缺乏深入思考总结

**规避**:
1. **撰写前规划**: 在框架构建阶段确定每章需要的插图
2. **工具调用**: 使用seedream/TikZ等工具生成专业框图
3. **思考可视化**: 将抽象概念转化为直观图表
4. **必含图表**:
   - 方法分类框架图（树状/层次结构）
   - 技术路线图（流程/时间线）
   - 对比示意图（多维度对比）
   - 系统架构图（模块关系）

### ❌ 案例7: 空虚标题

**现象**: 一个标题下只有一句话，连续换行但无解释

**根因**:
- 撰写设计到撰写实现脱节
- 缺乏内容支撑时仍强行分小节
- 未基于真实文献扩充内容

**规避**:
1. **内容优先**: 确保有足够内容支撑再设小标题
2. **合并精简**: 内容不足时合并到上级标题
3. **文献支撑**: 每个观点必须有文献支撑
4. **充实段落**: 每段至少3-5句，深入阐述

### ❌ 案例8: 结构错乱

**现象**: 参考文献后加附录，展望后加前置章节

**根因**:
- 为凑页数临时添加内容
- 未按逻辑顺序组织
- 缺乏整体规划

**规避**:
1. **先框架后内容**: 严格按7章标准结构撰写
2. **逻辑顺序**: 引言→理论→方法→实验→展望→结论
3. **前置内容前置**: 方法论章节必须在实验之前
4. **拒绝拼凑**: 不临时添加与正文无关的内容

## 核心教训（来自失败案例RL_Flight_Survey）

### 教训0: 主代理必须亲自完成核心工作（最关键）

**原则**: 文献搜集可以辅助，但**阅读、撰写、反思、改进必须由主代理亲自完成**，绝不委托给子agent。

**原因**:
- 子agent缺乏长期记忆和上下文理解
- 子agent容易产生内容碎片化、逻辑不连贯
- 主代理才能确保学术诚信和内容深度
- 亲自撰写才能实现真正的学习和成长

**执行标准**:
- **Phase 1 文献阅读**: 主代理亲自阅读每篇文献摘要，提取核心观点
- **Phase 3 内容撰写**: 主代理基于文献笔记亲自撰写每个段落
- **Phase 4 可视化**: 主代理亲自设计框图逻辑，可调用工具生成
- **Phase 6 反思改进**: 主代理亲自分析质量问题，制定改进方案

**榜样**: LLM_Survey_v3_2025.pdf —— 详细、完整、深入，格式优美，内容丰富专业的综述类论文

### 教训1: 学术诚信是底线

**问题**: 为凑页数编造了[30]-[252]共220+篇虚假文献

**反思**:
- 调研收集了文献列表，但没有阅读内容
- 用训练数据生成综述，而非基于调研结果
- 面对无话可写的困境，选择了编造而非深入

**改进**:
- 文献调研必须伴随内容阅读和理解
- 建立`literature_notes.md`记录每篇文献的核心观点
- 撰写时只使用已理解的文献内容
- 页数不够时，深入分析已有文献，而非编造新文献

### 教训2: 可视化必须前置

**问题**: 56页综述没有一个框图

**反思**:
- 未在撰写前规划插图位置
- 未调用生图工具准备可视化
- 对调研结果缺乏深入思考总结

**改进**:
- 新增Phase 0: 可视化规划（撰写前完成所有框图）
- 强制要求5+张专业框图
- 将抽象概念转化为直观图表

### 教训3: 拒绝空虚结构

**问题**: 大量标题下只有一句话，连续换行但无解释

**反思**:
- 撰写设计到撰写实现脱节
- 缺乏内容支撑时仍强行分小节
- 未基于真实文献扩充内容

**改进**:
- 每个小标题下至少3-5段深入阐述
- 内容不足时合并到上级标题
- 基于文献笔记充实每个段落

### 教训4: 结构必须符合逻辑

**问题**: 参考文献后加附录，展望后加前置章节

**反思**:
- 为凑页数临时添加内容
- 未按逻辑顺序组织
- 缺乏整体规划

**改进**:
- 严格按7章标准结构撰写
- 方法论章节必须在实验之前
- 拒绝拼凑与正文无关的内容
