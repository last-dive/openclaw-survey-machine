# Survey Evolution Skill

## 版本信息

- **版本**: 1.0.0
- **基于**: survey-writer v2.1.0 + survey-expander v1.0.0
- **适用场景**: 综述论文自查、迭代改进、质量提升

---

## 一句话介绍

**Survey Evolution** 是综述写作的最后一公里——通过多维度质量检查、迭代改进和版本管理，将综述初稿打磨至 A+ 可投稿水平。

---

## 核心原则

### 1. 综述的价值准则

> **重要**：综述类论文（Survey/Review）通常不需要实验章节。评委评估的是：
> - 文献覆盖度
> - 分类框架的原创性和清晰度
> - 批判性分析的深度
> - 未来方向的洞察力

### 2. 质量驱动迭代

- **先诊断，后改进**：先全面检查，再针对性修改
- **版本管理**：每次重大改进都是一次版本迭代（v2, v3...）
- **A+ 目标**：以可投稿顶刊为标准

### 3. 学术诚信底线

- **0 编造**：所有引用必须真实
- **0 空洞**：每个章节必须有实质内容
- **0 孤立**：引用必须与正文关联

## 多维度质量检查体系

### 8 维度评估（100 分制）

| 维度 | 分值 | 检查项 | 标准 |
|------|------|--------|------|
| **结构完整性** | 15 | 章节齐全，无截断 | 7-8 章完整 |
| **引言质量** | 10 | 研究背景、问题定义、组织结构 | 逻辑清晰，吸引读者 |
| **分类框架** | 15 | 原创性、清晰度、覆盖度 | 树状结构，无遗漏 |
| **内容深度** | 15 | 每类方法的原理、优缺点、局限性 | 批判性分析 > 10 处 |
| **引用系统** | 15 | 格式规范、文献真实、分布合理 | 不少于50%文献在正文中存在明确交叉引用，0 ??，100% 真实 |
| **图表质量** | 10 | 数量充足、清晰无重叠、专业美观 | 5+ 张，无重叠 |
| **排版规范** | 10 | 格式统一、交叉引用正确、无孤立列举 | 无警告 |
| **未来方向** | 10 | 具体性、洞察力、可操作性 | 具体可行 |

### 评级标准

| 等级 | 分数 | 说明 | 行动 |
|------|------|------|------|
| **A+** | 90-100 | 可投稿顶刊 | 完成 |
| **A** | 80-89 | 可投稿核心期刊 | 微调后投稿 |
| **B+** | 70-79 | 需进一步完善 | 针对性改进 |
| **B** | 60-69 | 需大幅修改 | 结构性调整 |
| **C** | <60 | 不合格 | 重写 |

## 使用方法

### 触发方式

```
请你使用 survey-evolution 检查并改进这篇综述：
- 输入：综述文件路径或内容
- 目标：达到 A+ 水平（90+ 分）
- 输出：质量报告 + 改进版本
```

### 执行流程

```
输入初稿 → 8维度检查 → 生成质量报告
    ↓
总分 >= 90? 
    ↓ 是
✅ 达到 A+
    ↓ 否
识别最低分维度 → 针对性改进 → 生成 v2 版本 → 重新检查
```

## 详细检查清单

### ✅ 结构完整性（15 分）

**检查项**：
- [ ] 是否有引言章节（背景、问题、贡献、组织）
- [ ] 是否有基础理论/方法分类章节（至少 3 章）
- [ ] 是否有未来方向/展望章节
- [ ] 章节编号是否连续，无跳跃
- [ ] 是否在 `\end{document}` 前结束

**扣分项**：
- 引言缺失：-5 分
- 展望缺失：-3 分
- 章节残缺：-2 分/章

---

### ✅ 引言质量（10 分）

**检查项**：
- [ ] 是否清晰定义了研究问题
- [ ] 是否说明了研究背景和意义
- [ ] 是否概述了现有方法的不足
- [ ] 是否明确了本文的组织结构

**优秀引言模板**：
```
随着[领域]的快速发展，[问题]成为制约[应用]的关键瓶颈。
现有方法在[方面]取得进展，但仍面临[挑战]。
本文旨在[目标]，主要贡献包括：
1. 提出了...
2. 系统性地分析了...
3. 指出了...
```

---

### ✅ 分类框架（15 分）

**检查项**：
- [ ] 是否采用树状/层次结构分类
- [ ] 各类别之间是否有清晰的边界
- [ ] 是否覆盖了该领域的主要方法
- [ ] 分类标准是否统一（如按原理、按应用、按时间）

**优秀框架示例**：
```
第3章 [方法A]
  3.1 [子类A1]
  3.2 [子类A2]
第4章 [方法B]
  4.1 [子类B1]
  4.2 [子类B2]
第5章 [方法C]
  5.1 [子类C1]
  5.2 [子类C2]
```

---

### ✅ 内容深度（15 分）

**检查项**：
- [ ] 每个方法是否有原理说明
- [ ] 每个方法是否有优缺点分析
- [ ] 每个方法是否有局限性分析
- [ ] 是否有方法对比表格
- [ ] 批判性分析是否 > 10 处

**扣分项**：
- 空虚标题（只有一句话）：-3 分/处
- 无批判性分析：-5 分
- 无方法对比：-3 分

---

### ✅ 引用系统（15 分）

**检查项**：
- [ ] 是否使用 `thebibliography` 或 BibTeX
- [ ] 正文引用是否正确（无 `??`）
- [ ] 所有 `\bibitem` 是否对应真实文献
- [ ] 近 5 年文献是否占 60%+
- [ ] 顶会顶刊是否占 70%+

**扣分项**：
- `??` 引用：-5 分/处
- 编造文献：直接 0 分（致命）
- 引用分布不合理：-3 分

---

### ✅ 图表质量（10 分）

**检查项**：
- [ ] 是否有系统架构图/方法分类图
- [ ] 是否有方法对比表格
- [ ] 是否有技术路线图（可选）
- [ ] TikZ 图表是否无重叠
- [ ] 表格是否使用三线表格式

**优秀图表清单**：
- [ ] 方法分类框架图（树状/层次）
- [ ] 方法对比表（优缺点、适用范围）
- [ ] Sim-to-Real 技术路线图（如果适用）
- [ ] 算法流程图（如果适用）

**扣分项**：
- 无任何图表：-5 分
- 图表重叠/混乱：-3 分
- 表格不规范：-2 分

---

### ✅ 排版规范（10 分）

**检查项**：
- [ ] 是否有孤立列举（`(1)(2)(3)`）
- [ ] 交叉引用是否正确（`图~\ref{}`、`表~\ref{}`）
- [ ] 公式编号是否连续
- [ ] 编译是否有错误/警告

**扣分项**：
- 孤立列举：-2 分/处
- 交叉引用错误：-1 分/处
- 编译警告：-1 分/处

---

### ✅ 未来方向（10 分）

**检查项**：
- [ ] 是否指出技术挑战
- [ ] 是否预测研究趋势
- [ ] 建议是否具体可行
- [ ] 是否与本文分类框架呼应

**优秀未来方向模板**：
```
未来研究方向可能包括：
1. [挑战1]：...[具体说明]
2. [趋势2]：...[具体说明]
3. [应用3]：...[具体说明]
```

## 迭代改进流程

### 版本管理规范

| 版本 | 说明 | 触发条件 |
|------|------|----------|
| v1 | 原始初稿 | Writer/Expander 输出 |
| v2 | 第一轮改进 | 第一轮 Evolution 检查后 |
| v3 | 第二轮改进 | 第二轮 Evolution 检查后 |
| ... | 持续迭代 | 直到达到 A+ |

### 改进策略

**当某个维度 < 60% 时**：
1. 暂停其他改进
2. 聚焦该维度
3. 完成后重新检查

**当总分 >= 90 时**：
1. 最终质量确认
2. 生成 `quality_report_vX.md`
3. 输出 `survey_final_vX.tex`

## 与 Survey Writer/Expander 的衔接

### Workflow

```
Survey Writer → Survey Expander → Survey Evolution
     ↓              ↓                ↓
   初稿 v1        扩展 v1         检查 + 改进
                                     ↓
                              v2, v3, ... → A+
```

### 关键原则

1. **Evolution 是质量守门员**：只有达到 A+ 才能停止迭代
2. **不妥协的底线**：学术诚信、文献真实、结构完整
3. **渐进式改进**：每次只聚焦最严重的问题

## 常见问题

### Q: 综述真的不需要实验章节吗？

A: 大多数综述（Survey/Review）不需要原创性实验。评估重点是文献梳理、分类框架和批判性分析。但如果综述包含"实证综述"（Empirical Review）类型，可能需要实验对比。

### Q: 什么时候可以停止迭代？

A: 当总分 >= 90 且所有维度 >= 70 时，可以认为达到 A+ 水平。

### Q: 如果某个维度始终无法提升怎么办？

A: 分析原因：
- 如果是结构性问题，可能需要重写该章节
- 如果是内容不足，可能需要补充更多文献
- 如果是格式问题，使用工具自动修复
