## 核心创新

**1. 上下文压缩型多 Agent 协作**

不同于 LangChain 的 RAG 路线（检索→向量库→拼接→生成），本系统采用**子 Agent 调研→压缩为引用词条（≤50条）→直接注入上下文**的方案。上百篇文献的精华以结构化词条形式存在，而非散落在向量数据库中——更简单、更快、更可靠。

**2. 质量守门员流水线**

Writer → Expander → Evolution 三阶段各有明确质量门禁：
- Writer 输出需通过 6 维度检查（≥60分）
- Expander 扩充要求末级标题 ≥500 字
- Evolution 质检需达到 8 维度 ≥90分（A+）方可交付

**3. 学术诚信内嵌机制**

禁止编造原则贯穿全流程——每一条引用必须来自真实调研到的文献，每一处扩充必须有文献支撑。8 类失败案例（文档截断、引用??、孤立列举、框图重叠、学术造假⚠️、空虚标题、结构错乱、缺少框图）内置规避方案。

## 一、项目概述

### 1.1 什么是综述永动机

综述永动机是基于 **OpenClaw Multi-Agent 架构** 的智能综述撰写系统，融合 **Writer（撰写）、Expander（扩展）、Evolution（迭代）** 三大核心机制，实现从问题提出到成稿交付的全流程自动化。

> **一句话总结：综述永动机 —— 让 AI 归纳"已知"，让人探索"未知"。**

### 1.2 它能做什么

- ✅ **一键生成综述**：输入研究方向，自动完成文献调研、结构规划、内容撰写与图表生成
- ✅ **持续迭代优化**：通过内置评审机制不断自我改进，直至达到 A+ 学术标准
- ✅ **交付即用成果**：输出可直接投稿的 LaTeX 论文，含规范引用、三线表与科研级图表

### 1.3 解决什么问题

传统综述撰写存在 **"三重困境"**：

1️⃣ **文献调研耗时** —— 手动查阅数百篇文献，常需数周时间  
2️⃣ **结构反复调整** —— 逻辑框架易失衡，导致大量重写  
3️⃣ **写作效率低下** —— 逐字打磨挤占创新思考时间  

综述永动机将研究者从 **重复性劳动** 中解放，把时间归还给真正的科学探索。

### 1.4 核心指标

| 指标 | 数值 |
|------|------|
| 输入 | 一个研究主题 |
| 输出 | 30-50 页 LaTeX 综述 PDF，80-100 篇真实引用 |
| 效率提升 | 相比传统方式 **超 150 倍** |
| 质量评级 | A+（90+ 分），达核心期刊投稿要求 |
| 覆盖领域 | 控制科学、航空航天、机器人、人工智能等 |

### 1.5 解决痛点一览

| 痛点 | 传统方式 | Survey Machine |
|------|----------|----------------|
| 文献调研 | 手动检索，耗时数天 | SerpAPI 自动抓取 100+ 篇 |
| 内容空洞 | 凑字数，编文献 | 严格基于真实文献，禁止编造 |
| 结构混乱 | 想到哪写哪 | 7 章标准结构，逻辑清晰 |
| 页数不足 | 水文字 | 深度扩展，批判性分析 |
| 质量参差 | 写完即止 | 8 维度质量检查，A+ 标准 |
| 格式不规范 | 逐项调整 | LaTeX 模板，一键编译 |

## 三、核心模块详解

### 3.1 Survey Writer — 撰写引擎（v2.0.0）

Survey Writer 是整个流水线的内容生产核心，基于 UAV_Delay_Survey_v3 的真实成功经验构建，经历过惨痛的失败教训迭代。

#### 6 阶段工作流

| 阶段 | 名称 | 时长 | 关键输出 |
|------|------|------|---------|
| Phase 0 | 可视化规划 | 10min | figures/ 目录（5+ 张图） |
| Phase 1 | 文献调研与阅读 | 60min | literature_pool.json |
| Phase 2 | 框架构建 | 20min | framework.yaml（7章结构） |
| Phase 3 | 内容撰写 | 4-5h | survey_draft.tex（30+页） |
| Phase 4 | 可视化绘制 | 30min | figures/*.tex |
| Phase 5 | 引用系统 | 20min | thebibliography 环境 |
| Phase 6 | 质量检查 | 30min | quality_report.md |

#### 7 章标准结构

```
第1章 引言
第2章 基础理论
第3章 方法A（按原理/应用分类）
第4章 方法B
第5章 方法C
第6章 实验与应用
第7章 未来方向
```

#### 核心设计原则

- **原则 1：禁止编造** — 每一条引用必须来自真实调研到的文献，100 篇文献的摘要就是最好的写作素材
- **原则 2：批判性分析** — 每介绍一个方法，立即分析其局限性，批判性分析 > 10 处
- **原则 3：可视化前置** — Phase 0 先规划所有图表，确保技术路线清晰

### 3.2 Survey Expander — 扩展引擎（v1.1.0）

专用于初稿完成后页数不足时的合规扩展。**不是水字数，而是基于文献的深度扩充。**

#### 5 阶段工作流

```
Phase 1  分析诊断    →  识别过短章节（<500字）、单句段落、图表缺口
Phase 2  内容扩充    →  5种扩充策略（深度阐述/案例分析/对比讨论/文献综述/局限性补充）
Phase 3  图表增强    →  框架图/流程图/对比表（≤30%总页数）
Phase 4  文献完善    →  补充 DOI/arXiv 链接
Phase 5  质量检查    →  6维度检查
```

#### 四段式分析方法（强制）

每个方法必须包含完整的四段式分析：

```
① 原理：该方法的技术原理（基于文献）
② 优势：为什么有效，附具体数据或结论（基于文献）
③ 局限：该方法的不足、已知问题、适用边界（必须基于文献）
④ 适用：该方法最适合什么任务、什么条件下有效
```

### 3.3 Survey Evolution — 质检进化引擎（v1.0.0）

综述写作的"最后一公里"——通过多维度质量检查和迭代改进，将初稿打磨至 A+ 可投稿水平。

#### 8 维度质量检查体系（100 分制）

| 维度 | 分值 | 检查要点 |
|------|------|---------|
| 结构完整性 | 15 | 7-8章完整，无截断 |
| 引言质量 | 10 | 背景/问题/贡献/结构清晰 |
| 分类框架 | 15 | 树状结构，边界清晰，覆盖全面 |
| 内容深度 | 15 | 批判性分析 > 10 处 |
| 引用系统 | 15 | 0 ??, 100% 真实 |
| 图表质量 | 10 | 5+张，无重叠，专业美观 |
| 排版规范 | 10 | 无孤立列举，交叉引用正确 |
| 未来方向 | 10 | 具体可行，有洞察力 |

#### 评级标准

| 等级 | 分数 | 说明 |
|------|------|------|
| A+ | 90-100 | 可投稿顶刊 |
| A | 80-89 | 可投稿核心期刊 |
| B+ | 70-79 | 需进一步完善 |
| B | 60-69 | 需大幅修改 |
| C | <60 | 不合格，需重写 |

## 四、工具模块

### 4.1 SerpAPI 文献检索

自动抓取 arXiv、IEEE、ACM、知网等数据库，按主题聚类，质量筛选（顶会顶刊优先），目标 100+ 篇真实文献。

### 4.2 Seedream AI 配图生成

使用字节跳动 Seedream 5.0 模型，支持中文提示词，生成系统架构图、方法分类图、技术路线图。工作流：生成 → 去灰底后处理 → 嵌入 LaTeX。

### 4.3 TikZ 框图生成

精确控制，适合复杂控制框图。使用绝对坐标避免节点重叠，配合 Seedream 实现双轨制（AI快速生成 + TikZ精确绘制）。

### 4.4 LaTeX 排版

标准 thebibliography 引用环境（禁止 enumerate）、三线表格式（booktabs）、交叉引用规范化（图~\ref{}、表~\ref{}）、XeLaTeX 编译支持中文。

## 六、质量保障体系

### 6.1 全流程质量门禁

```
Writer 输出  ──→  Expander 扩充  ──→  Evolution 质检
  6维度检查        6维度检查          8维度检查
  (≥60分过关)      (末级标题≥500字)    (≥90分A+)
```

### 6.2 学术诚信底线

| 行为 | 允许 | 禁止 |
|------|------|------|
| 文献引用 | ✅ 基于调研到的真实文献 | ❌ 编造虚假文献凑数 |
| 内容生成 | ✅ 基于文献笔记撰写 | ❌ 用训练数据生成 |
| 页数达标 | ✅ 深度分析已有文献 | ❌ 水字数或添加无关内容 |
| 图表生成 | ✅ Seedream + TikZ | ❌ 截取他人图片 |

### 6.3 失败案例库

系统内置 8 类失败案例及规避方案：

- ❌ **文档截断** — 错误的 `\end{document}`
- ❌ **引用失败** — `[??]`
- ❌ **孤立列举** — 单行 itemize
- ❌ **框图重叠** — matrix 布局问题
- ❌ **学术诚信** — 编造文献 ⚠️ 致命
- ❌ **缺少框图** — 未规划可视化
- ❌ **空虚标题** — 内容不足强行分节
- ❌ **结构错乱** — 参考文献后加附录
